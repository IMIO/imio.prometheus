===============
imio.prometheus
===============

This package adds a ``@@metrics`` view used by Prometheus. It extends the view
of `collective.prometheus <https://pypi.org/project/collective.prometheus/>`_
with labels identifying the instance:

- ``plone_service_name``: the ``SERVICE_NAME`` environment variable
  (default ``local-plone``);
- ``compose_service``: the ``HOSTNAME`` environment variable
  (default ``localhost-instance``).

The view is registered on any Zope object, so ``http://localhost:8080/@@metrics``
works without a Plone site.

Compatibility
-------------

Version 2.x supports Plone 6.2 on Python 3.10 to 3.14. Use 1.0.x for older
Plone versions and Python 2.

Installation
------------

Add ``imio.prometheus`` to the dependencies of your project and load its ZCML,
for instance with ``zcml_package_includes: 'imio.prometheus'`` in the
`cookiecutter-zope-instance <https://github.com/plone/cookiecutter-zope-instance>`_
configuration, or ``zcml = imio.prometheus`` in a buildout.

Development
-----------

Requires `uv <https://docs.astral.sh/uv/>`_. This installs Plone 6.2.3 in
``.venv`` (set ``PLONE_VERSION`` for another 6.2.x release) and
starts Zope on http://localhost:8080 (``admin`` / ``admin``)::

    make install
    make start

Tests and QA run through tox, as the CI does::

    make test        # Plone 6.2.3
    make test-all    # lint, every Plone / Python combination, dependencies
    uvx --with tox-uv tox -e py314-plone62
    make check       # format + lint (pre-commit hooks run with prek)

``.editorconfig``, ``.flake8``, ``.gitignore``, ``.pre-commit-config.yaml``,
``tox.ini``, ``.github/`` and the tool sections of ``pyproject.toml`` are
generated by `plone.meta <https://github.com/plone/meta>`_: change
``.meta.toml``, then run
``uvx --from plone.meta config-package --no-commit --branch current .``.
